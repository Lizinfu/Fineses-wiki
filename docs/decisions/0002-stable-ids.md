# ADR 0002：稳定 ID 不随标题或 URL 变更

- **状态**：已采纳
- **日期**：2026-08-03

## 决策

公开实体的稳定 ID 仅使用小写字母、数字、点号和连字符，并在创建后保持不变。实体关系、来源和派生数据仅引用稳定 ID，不引用显示标题或页面 URL。

## 后果

- 内容重命名、语言调整和目录重组不会破坏关系；
- URL 变更通过 Hugo 顶层 `aliases` 保留旧访问地址；
- 重复或格式不合法的 ID 会由 `npm run wiki:validate` 阻止；
- 已公开 ID 的修正属于迁移，不得通过直接替换后忽略旧引用来完成。

详细规则见 [内容模型](../content-model.md)。
