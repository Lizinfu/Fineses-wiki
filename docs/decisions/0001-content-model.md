# ADR 0001：内容模型以稳定 ID 和统一关系数组为核心

- **状态**：已采纳
- **日期**：2026-08-03

## 决策

独立世界观实体按实体类型存放在 `content/` 中，每个公开实体使用不可变的 `params.id`。跨实体事实使用统一的 `params.relations` 数组表达，而不使用按国家、组织或阵营复制文件的方式表达。

## 后果

- 标题、URL 和目录可以演进，而关系仍保持稳定；
- 构建可生成 ID 索引和反向链接，避免双方手工同步；
- 编辑者需要理解最小 Front Matter 契约，并在新增实体时填写关系和分类；
- 改变字段命名、ID 规则或关系语义时必须提供迁移方案。

详细规范见 [内容模型](../content-model.md) 与 [关系指南](../relationship-guide.md)。
