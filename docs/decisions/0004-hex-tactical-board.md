# ADR 0004：实体六边形战术沙盘

- 状态：按作者指示实施，视觉细节持续迭代
- 日期：2026-10-31

作者明确目标是“由六边形块组成、有立体感的战术沙盘”，并要求不使用连续起伏模拟地形。保留 PixiJS 与固定视角 2.5D；移除 ADR 0003 中的连续高度纹理和法线着色实现。

地形使用整数层级、平整顶面、显式侧面、物理接缝和硬投影。世界与国家使用同源国土块；城市以对称细块和独立六边形基座细化。图标、河流、建筑和国界沿同一块面高度定位，拾取反向回到逻辑地理归属。

elevation.level 等参数仅是艺术层级，不代表米或真实测绘海拔。高风原野仍不是高原；未知地形维持平整基础块。城市和河道继续保持可替换示意，不扩写世界观事实。

不新增渲染引擎、后端或发布依赖，不恢复 SVG 地图方案。本地参考图继续放在 Git 忽略目录。
