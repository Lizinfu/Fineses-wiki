# ADR 0004：实体六边形战术沙盘

- 状态：离散块体与 2.5D 路线已实施；城市美术由 [ADR 0007](0007-city-white-model.md) 细化
- 日期：2026-10-31

当前维护入口见[地图功能与维护指南](../BUILDER/MAP_MAINTENANCE.md)；本记录说明采用离散块体的原因。

作者明确目标是“由六边形块组成、有立体感的战术沙盘”，并要求不使用连续起伏模拟地形。保留 PixiJS 与固定视角 2.5D；移除 ADR 0003 中的连续高度纹理和法线着色实现。

地形使用整数层级、平整顶面与实际高差处的显式侧面。世界与国家使用同源国土块；城市使用独立细块组成不规则地面片段，细化为白模型建筑。同高连续区域内部不绘制内缩缝、侧壁、高光或接触阴影；真实台阶、海岸与国界保留。图标、河流、建筑和国界沿同一块面高度定位，拾取反向回到逻辑地理归属。

2026-11-08 第一轮质感调整只在现有底色上增加统一中性方向光、环境补光与基础接触阴影，不为不同模型新增配色、材质类别或功能灯。`lighting.mjs` 提供中性光照与面法线，`surface.mjs` 计算共享边与同高平面的连续边界环，`pixi-renderer.ts` 静态缓存顶面和基础阴影。六角网格默认关闭，主动开启时以独立辅助线叠加；城市黑色缺失平面默认无普通拼缝，紫色数据纹路继续保留。完整接收面投影和复杂遮挡仍在本轮实现边界之外。

2026-11-10 浅色界面迭代覆盖上述城市缺失平面的黑紫配色：现行表现为浅灰连续底面与细微灰色数据纹路，六角网格仍默认关闭，减少动态效果模式保持纹路静止。侧栏与 HUD 同步采用浅灰面板；世界冷蓝海面、浅色陆地、特殊地貌与冷白城市建筑保留原配色。此次调整不改变地图数据、几何、光照、拾取或层级进出规则。

`elevation.level` 等参数仅是艺术层级，不代表米或真实测绘海拔。高风原野仍不是高原；未知地形维持平整基础块。卡夏·欧尔莱特的路网保持辐射秩序，地势、建筑密度和功能分区按作者规划处理；具体街坊与建筑轮廓仍是可编辑的美术数据。

不新增渲染引擎、后端或发布依赖，不恢复 SVG 地图方案。本地参考图继续放在 Git 忽略目录。
