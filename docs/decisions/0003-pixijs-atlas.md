# ADR 0003：地图切换到 PixiJS

- 状态：已采纳；作者已确认后续继续使用 PixiJS
- 日期：2026-10-31

作者已查看 PixiJS 样板，并确认后续采用此路线。地图页面使用锁定的 PixiJS 8.22.0 与 WebGL2；保留 Hugo、GitHub Pages、稳定实体 ID、地图源图与参考图。删除旧 SVG 地图绘制代码及 CSS，保留属于百科资产的 SVG 徽记。

使用单世界坐标和单相机，绘制、标签、命中和倾斜共用数学契约。政治掩膜与显示格网分开，避免非等比配准扭曲网格；首都锚点与城市中心在世界坐标中严格一致。

已清理旧 SVG 专属的样式标记、分块参数、每地图相机参数、背景标签配置及模板序列化分支。伊琳沃克旧地址继续兼容，地图源图与本地参考图保留。未定义的河道、城区与高程继续保持可替换的示意数据，美术细节在此路线持续迭代。
