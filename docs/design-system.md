# 设计系统与组件边界

## 当前视觉方向：深色机能档案

界面以近未来、功能主义和极简主义的公开档案系统为方向。石墨黑底、冷灰材质、白色文字、青蓝信号色、细分隔线和局部几何遮罩构成主要视觉语言。背景通过原创网点、网格与低对比光域叠层形成质感。中文承担主要导航与阅读语义；英文展示字使用本地 Oswald 可变字体（SIL OFL），编号、日期和辅助代码使用等宽字体。标题、正文、档案事实和系统编目应有明确层级。

- **深色为默认**：新访问者和无 JavaScript 页面使用深色界面；已保存的深浅偏好继续生效。浅色作为可选阅读模式，组件仍通过语义令牌配色。
- **地图固定浅色**：地图工作区保留冷蓝海面、浅色陆地和冷白城市模型，目录与操作面板使用浅色体系。全站深色偏好不把地图工作区转换成深色沙盘。
- **结构先于装饰**：优先通过对齐、间距、字重、分隔和真实选中状态组织信息。切角、材质、图章与粒子仅作少量辅助，不覆盖正文或代替功能提示。
- **长文优先**：正文拥有稳定的阅读宽度。实体页不在全局左右轨道之间再嵌入一个资料侧栏；目录与档案摘要共享右轨。

## 文件层次

样式位于 `assets/styles/`：

```text
tokens.css       颜色、间距、字号、边框等设计令牌
reset.css        基础重置
base.css         全局基础规则
typography.css   排版规则
layout.css       页面壳层和布局
precision.css    全站精密档案的组件收敛与页面组合
industrial.css   深色材质、图形、字体与组件美术合成
components/      可复用组件
pages/           特定页面样式
```

新增视觉值时优先扩展 `tokens.css`，而不是在组件中散落硬编码颜色、间距和动画时长。组件样式必须只负责自身结构；页面组合方式应放在 `pages/` 或 Hugo 模板中。

动效增强位于 `assets/styles/components/motion.css`、`assets/scripts/motion.ts`，由主脚本初始化。首页点阵由独立入口 `assets/scripts/signal-entry.ts` 和 `signal-field.ts` 实现，仅首页加载 Three.js；地图继续按页面加载 PixiJS。主题偏好由 `assets/scripts/theme.ts` 和 head 中的早期主题设置共同处理，避免初始主题与已保存的偏好不一致。

## 组件原则

- 实体信息、关系、反向链接、时间线和媒体优先由 `layouts/_partials/` 中的数据组件输出；
- Markdown 特殊表现通过 `layouts/_shortcodes/` 提供，避免复制 HTML；
- 原生脚本按功能置于 `assets/scripts/`，默认增强 HTML，而不接管正文可读性；
- 新增交互必须有键盘行为、焦点样式、空状态和无 JS 回退方案。

## 实体阅读与移动端

首页“推荐阅读”由 `config/_default/params.toml` 中的 `home_recommendations.items` 按顺序选择，引用既有稳定 ID、图片及可选摘要，不给任何实体预设特殊地位。轮播使用原生横向滚动和普通链接；无 JavaScript 也可浏览全部推荐。自动轮播尊重动效偏好，悬停、焦点、手动操作、离屏和后台状态会暂停，提供显式播放／暂停及前后切换控件。

`layouts/page.html` 与 `layouts/_partials/pages/entity-branch-view.html` 共用实体头部、编目、正文与附录组件。拥有正文的国家 Branch 也应输出目录。

- 桌面右轨将本页目录与档案摘要集中呈现，正文内部不再放置独立的信息卡列。
- 宽度不超过 `73.75rem` 时，正文前提供原生 `details` 折叠的“本页目录”和“档案摘要”。隐藏桌面右轨时，移动入口必须同时可用；名称、别名、年代、分类等事实不能随侧栏消失。
- 桌面和移动目录具有独立 DOM ID，均链接至同一组正文锚点。目录滚动高亮属于增强行为，普通锚点链接仍可独立使用。
- 系统编目、修订与复核记录使用折叠区降低默认信息密度。稳定 ID、馆藏号、Schema、来源、关系方向、反向链接及子页面链接仍保留。
- 现实编辑日期通过 `layouts/_partials/ui/display-date.html` 展示。缺失日期和 Hugo 的 `0001` 零日期显示为“未记录”，不生成虚假的日期；世界内日期继续使用时间线自身的显示与排序规则。

## 动效与粒子

动效表达档案载入、选择和定位，不模拟必须等待的系统启动。交互不应等动画结束才响应；正文也不应依赖滚动揭示后才可阅读。

| 场景 | 表现与边界 |
|---|---|
| 原生跨页 | 支持跨文档 View Transitions 的同源浏览器可使用正文淡出、淡入与少量位移；仍采用 Hugo 原生多页链接。未支持时按普通文档导航。 |
| 页面入场 | 约 `280ms` 的正文入场和短暂定位线。避免与浏览器原生转场重复播放，也不强制重播前进／后退恢复的页面。 |
| 导航与卡片 | 颜色、边框和局部轻位移提供反馈；悬停效果不能成为发现操作的唯一线索。 |
| 原生折叠区 | 展开内容可进行约 `160ms` 的淡入与轻位移；折叠语义和操作仍由原生元素承担。 |
| 首页点阵 | 独立透明 WebGL 层呈现原创环轨、徽记和地形三种图形；同一组点聚合、解体与变形，指针扰动后恢复。切换按钮为原生按钮，支持键盘和触屏。图形为装饰，不承载实体关系或实际地图几何。 |
| 档案微粒 | 实体页头保留小型 Canvas 2D 装饰层；正文、搜索、时间线和地图画布不叠加粒子。避开文字与表单控件。首页不同时开启旧微粒层。 |
| 动态偏好 | 页头开关将偏好保存在当前浏览器；系统 `prefers-reduced-motion` 优先，关闭粒子、位移转场和其他非必要动画。 |

粒子在页面隐藏或装饰区域离屏时暂停；设置绘制频率、像素倍率和粒子数量上限。首页点阵与地图场景按页面互斥加载，不将 Three.js 加入通用站点脚本。关闭动效、系统减少动态、无 JavaScript 或 WebGL 不可用时展示静态 SVG，图形不因增强失败而消失。Canvas 为 `aria-hidden`，不拦截导航、滚动或键盘。以上为实现边界与预算，不代表任何设备上已测得的帧率、Lighthouse 分数或性能认证。

## 数据与构建边界

本轮只调整模板、样式、显示文案与渐进交互，不更改 `content/`、`data/`、Schema、稳定 ID、关系语义、地图几何、检索匹配规则或现有 URL。正文仍来自 Markdown，目录和事实卡仍消费同一份既有数据，派生数据继续通过原有构建流程生成。数据契约见[内容模型](content-model.md)，导航与内容目录的区分见[信息架构](information-architecture.md)。

页面保持现代、克制和可长时间阅读。图书馆批注可以保留独立的人文笔触；档案章、馆藏编号与轻量材质传递设定，不以低对比度、噪点、仿古字体或持续播放动画作为主要氛围手段。
