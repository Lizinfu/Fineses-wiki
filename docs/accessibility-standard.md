# 可访问性标准

本项目以“现代知识库可用性优先”为原则。图书馆叙事、主题切换和动画不能阻碍阅读、导航或搜索。

## 合并前人工检查

- 键盘可到达导航、搜索、抽屉、目录和所有新增交互；焦点清晰可见；
- 页面标题层级连续，主内容和辅助区域使用语义化结构；
- 图片有准确替代文字；纯装饰图片应避免产生无意义朗读；
- 不能只通过颜色传达状态、错误或可信度；
- 正文、链接、按钮和状态文本在默认主题下具有足够对比度；
- 在 320px 宽度下无阻断性横向溢出，表格与信息框可阅读；
- 禁用 JavaScript 后，正文、基础导航和目录仍可使用；
- 尊重 `prefers-reduced-motion`，动画不是获取信息的前提。

## 当前状态与后续门禁

当前 CI 已对渲染结果强制检查页面标题和本地资源/链接目标，并以 Playwright/axe 验证核心页面、跳过链接、移动导航和 WCAG A/AA 规则。缺少 `alt` 目前是报告警告而非阻断项，以便先清理既有内容；新增或修改图片不得新增此类警告。项目尚未配置 Lighthouse 性能预算或视觉快照回归；涉及模板、CSS、交互或图片组件的 PR 必须完成上述人工检查。下一批门禁将把代表页面的 Accessibility ≥95、Performance ≥90、Best Practices ≥95 转换为自动性能检查。
