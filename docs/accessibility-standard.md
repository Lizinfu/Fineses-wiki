# 可访问性标准

本项目以“现代知识库可用性优先”为原则。图书馆叙事、主题切换和动画不能阻碍阅读、导航或搜索。

## 精密档案界面的基本约定

- 浅色为默认，深色是读者可选模式；两个模式都应保持可读对比度、清晰焦点和状态文字。地图工作区固定为浅色，切换全站主题时仍需检查地图控件与标签。
- 正文是主要阅读区域。桌面目录与档案摘要共用辅助栏，不能挤压为难以阅读的窄正文列。
- 右轨隐藏时，正文前应同时提供原生折叠的“本页目录”和“档案摘要”。移动端须仍可访问名称、年代、分类与系统编目，不能只隐藏整个信息卡。
- 国家等 Branch 实体也应有目录；桌面与移动目录 ID 唯一，链接指向真实章节。高亮可增强定位，不替代锚点本身。
- 系统编目与修订记录可以默认折叠，稳定 ID、来源、关系、反向链接和既有 URL 均须保留。显示层将缺失与零日期标为“未记录”，不更改原始数据或世界内日期。

## 动态效果与渐进增强

`prefers-reduced-motion` 的系统偏好优先于站点保存的动效开关。开启减少动态效果后，不显示装饰粒子，不使用位移入场、平滑滚动或非必要转场；偏好在当前页面改变时也应及时生效。手动关闭动态效果具有同样的静态阅读目标，偏好存储不可用时页面仍须正常运行。

原生跨文档 View Transitions 属于可选增强，不将 Hugo 网站改为单页应用，不拦截链接来等待动画。浏览器未支持、脚本被禁用或装饰资源失败时，正文、导航、原生折叠区和普通锚点仍可使用；检索和地图分别保留馆藏目录、地点目录等既有回退入口。前进／后退应保留浏览器的阅读位置恢复行为。

粒子必须为纯装饰：使用 `aria-hidden`，不接管指针事件、不进入 Tab 顺序，也不触发朗读或状态播报。粒子只在首页介绍或实体页头的空白区域内活动，避开文字和控件；搜索、时间线、正文和地图画布不叠加粒子。页面隐藏或该装饰区域离屏时暂停绘制。任何动画都不得让交互变为暂时不可点击或要求读者等待。

## 合并前人工检查

- 键盘可到达导航、搜索、抽屉、目录和所有新增交互；焦点清晰可见，跳过链接能定位主内容；
- 原生 `details` 可用 Enter／空格展开与折叠，Tab 不进入隐藏内容；抽屉关闭后焦点返回触发控件；
- 页面标题层级连续，主内容和辅助区域使用语义化结构；
- 图片有准确替代文字；纯装饰图片应避免产生无意义朗读；
- 不能只通过颜色传达状态、错误或可信度；
- 正文、链接、按钮和状态文本在浅色、深色以及固定浅色地图工作区内具有足够对比度；
- 在 320px 宽度及放大阅读时无阻断性横向溢出；必要表格可局部横向滚动，目录与信息框仍可访问；
- 移动端触控目标足够大，关键操作和信息不依赖悬停；
- 同页目录等重复组件的 DOM ID 唯一，所有锚点有效；
- 禁用 JavaScript 后，正文、基础导航和目录仍可使用；
- 动效开关和系统减少动态效果均即时生效；切换主题、连续操作、离屏及后台恢复不产生重复绘制循环；
- 原生跨页、前进／后退和无转场支持的浏览器均可完成阅读与导航，动画不是获取信息的前提。

## 当前状态与后续门禁

仓库 CI 配置包含渲染页面标题、本地资源／链接目标检查，并通过 Playwright／axe 检查核心页面、跳过链接、移动导航和 WCAG A／AA 规则。缺少 `alt` 目前是报告警告而非阻断项，以便先清理既有内容；新增或修改图片不得新增此类警告。自动检查不能替代主题、移动阅读、原生折叠区和动态偏好的人工检查。

项目尚未配置 Lighthouse 性能预算或视觉快照回归；涉及模板、CSS、交互或图片组件的 PR 必须完成上述人工检查。后续性能门禁的目标仍为代表页面 Accessibility ≥95、Performance ≥90、Best Practices ≥95，这些是计划目标，不是本轮已测得的分数。本轮构建、浏览器检查和发布状态应以对应执行记录为准，文档更新本身不表示部署完成。
