# 编辑与写作规范

## 正文结构

- 页面标题由 Front Matter 的 `title` 输出；正文从 `##` 开始，不要重复写 `#`；
- 标题层级必须连续，不能从 `##` 跳至 `####`；
- `description` 应用一句话说明条目身份、范围或阅读价值；
- 标题、摘要、正文、关系和时间线必须描述同一对象和同一事件；结构校验不能自动发现叙事矛盾。

## 名称与检索

将正式名称写入 `params.names.official`；简称、原文名、旧称和别名分别写入相应 `names` 数组。必要时在顶层 `keywords` 添加读者可能实际输入的检索词。不要以中文标题作为关系键。

## 语气与世界内叙事

Wiki 是现代化图书馆界面。馆藏编号、可信度、批注、档案修复记录和世界内文献可以营造沉浸感，但不得遮挡读者理解所需的事实。警告和涂黑效果不是访问控制，也不能承载唯一的重要信息。

## 媒体、表格与引用

- 将条目私有图片放入所属 Page Bundle；
- 所有图片必须提供准确替代文字；
- 表格应有清晰表头，移动端仍可理解；
- 使用 shortcodes 时优先使用自动信息框、关系和来源；手工组件只用于无法由数据表达的特殊版式。
