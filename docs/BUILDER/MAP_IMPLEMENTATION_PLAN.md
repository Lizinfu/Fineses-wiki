# PixiJS 交互地图实施方案

> 当前权威实现 · 更新于 2026-10-31。旧 SVG 地图方案已撤下；历史实现从 Git 记录查阅。

## 目标与当前边界

地图服务于世界观探索。Hugo 和 GitHub Pages 负责静态内容与发布，地图页面使用锁定版本的 PixiJS 8.22.0 / WebGL2。没有服务器数据库、现实投影、导航计算或真实高程测绘。无 JavaScript 或无 WebGL2 时保留目录、要素说明与档案链接，不回退到 SVG 地图。

目标视觉为低多边形六边形战术沙盘：平整块面、可见厚度、离散台阶、冷灰蓝材质、克制的彩色国界与紧凑标签。作者明确不采用连续起伏、噪声或模糊地形阴影。PixiJS 路线继续使用；自动测试不能替代视觉检查。

## 当前内容

- L0：136 × 60 世界逻辑网格，8,160 格、2,671 陆地格、13 个现存政治区域、无人区及世界横向环绕。来源裁切排除原图白框，避免误生成为南北两排陆地。
- L1：13 国共用同一批实体国土块，聚焦后显示专题与地点。伊琳沃克的平地、原野和首都高点以少量台阶表达，河床为不逆流上升的离散层级，河流沿块面绘制。其他国家维持平整基础块，不生成虚构地形。
- L2：卡夏·欧尔莱特具有独立六边形基座、中心对称的细块地面、皇宫与立体街区；内部内容仅在城市视野显示。
- 地貌范围、相对高程、河道路径、城区外缘及内部布局为 provisional。相对高程不使用米。河流没有正式名称，源头与河口未定。首都仅确认是高风原野最高处，不推断为全国最高点。
- 输入支持拖拽、滚轮、双指缩放、键盘、按钮、目录与浏览器历史。默认斜俯视 y 比例为 0.78；块体通过显式顶面与侧面实现固定视角 2.5D，不支持自由三维旋转。

## 坐标与对齐

逻辑地理坐标先经 blocks.mjs 转为块体表面坐标（y 减去离散高度），再由同一相机投影。Pixi 图形、HTML 标签和河流使用同一表面变换；点击先拾取可见顶面或侧面，再回到逻辑归属。没有独立 CSS 地图缩放链。

1. 世界逻辑格为平顶 odd-q；连续位置为每张地图的 0–1 坐标，x 向东、y 向南。
2. space.mjs 读取生成器四参数配准并递归合成世界变换，统一缓存地图轮廓与范围。
3. 城市局部中心精确绑定 locations.yaml 的连续首都锚点；暂定城市外缘整体配准到同一锚点。该配准只针对示意城区，不声称其为正式测绘边界。
4. 世界和国家共用 L0 规则六边形的实体块体，避免切换时更换海岸或地形。国家细格掩膜继续保存为内容与未来细化接口，不再叠加一层平面细网格。
5. L1 国土来自同源 L0；L2 使用以首都为中心的轴向细格，保证 180° 对称。城市基座只是可替换示意，不是正式城区边界。
6. 位置、显示标签、百科 ID、政治状态和颜色各自独立。
7. 国家中心由同一政治掩膜的等面积六边形计算，大陆中心由区域内的实际陆地计算；凹形或离散岛屿的重心落海时回落到最近陆地格。环绕区域先展开接缝。`areaCenter` 缓存结果，源图重建后重新计算；仅显式提供 `label_anchor` 时使用手工覆盖。当前国家和大陆不再使用旧手工锚点。

## 渲染与层级

PixiJS 使用单 Canvas 和 GPU Graphics。每个地块具有平整六边形顶面及三个可见侧面，按由远及近的顺序绘制；每面使用单一颜色，体积来自几何、侧壁色差、锐利边缘及硬投影。旧的连续高度纹理、法线光照、正弦起伏与颗粒着色已删除。

- 世界实体块常驻，横向副本共享 Graphics 几何。中性色/政治色和分层/基础高度的组合按需创建并缓存。
- 国界沿本国块体顶面升高，约 1.8 屏幕像素，选中国家约 2.6 像素；城市层隐藏国界。
- 国家河流与城市细节按需缓存，空闲不重建几何。河流贴合分层河床；不绘制连续峡谷阴影。
- 城市坐落于六边形基座，地面细块保持中心对称。道路贴合块面，建筑具有平整屋顶与侧壁，皇宫标签定位到屋顶高度。
- 海面格网与逻辑世界共用坐标，随相机移动。关闭“块面描边”只隐藏描边，物理接缝和体积仍保留；关闭“地形层级”仅将地形归一为基础厚度。
- 当前 L1 进入/退出倍率为 0.50/0.44，L2 为 2.4/2.05，并要求相机中心位于目标范围。
- HTML 标签采用屏幕空间排列、优先级和碰撞避让，保持文字直立。国家徽记统一为 30 × 30 像素，倍率达到 0.28 后显示，城市层统一隐藏；视野中心国家和邻国遵循同一规则。先预留徽记的 44 × 44 点击区，再安排地名与剩余国家文字；文字挤不下时只收起文字，保持徽记锚点、名称提示和点击行为。徽记本身越界或与徽记/控件无法避让时才隐藏，仍可通过目录找到。
- 投影点对准块面上图标或主名称本体的中心，不使用说明或按钮留白作为中心。标签关闭通用按钮的位移过渡；高风原野与克莱尔平原的名称位于各自示意地形中心。
- 地图标签参与统一指针手势：短按打开资料，从标签开始拖拽或双指缩放则操作地图；拖拽不误触标签。Enter/Space 和辅助技术的原生点击继续可用。
- 首都文本从定位点向右展开，定位符号保持在真实锚点，避免较宽文本覆盖邻近徽记。与国家标签重复的旧国家地点标识保留目录和深链接，不再额外绘制同名标签。
- 档案和要素资料显示在目录面板，不在地图中央叠加浮动卡片。
- 绘制由输入和尺寸变化触发，空闲时不持续运转 ticker；相机过渡尊重 reduced-motion。

目前掩膜与配置仍由 HTML 序列化，未实现独立网络分块。更多城市、历史政治、精确行政区和真实高程待后续资料与验证。

旧版的 `context`、`chunk_size`、`appearance`、每地图缩放/中心、显示网格 `gap` 及区域 `style_token` 已移除；这些字段不能配置当前渲染器。逻辑网格与预算仍在 `layers.yaml`，相机及显示阈值在 `app.ts`，材质与边界在 `pixi-renderer.ts`，标签样式在 CSS。来源采样器自己的网格参数仍属于 `sources.yaml`，不受这次显示参数清理影响。

## 质量门禁

- wiki:validate：内容、来源一致性、地图和要素校验、严格 TypeScript 检查、纯数学与几何测试。
- test:maps：验证首都与城市中心对齐、倾斜投影逆变换、指针锚点、政治命中、环绕、同源裁切、规则六边形、中心对称与河流方向。
- 块体测试：顶面平整、侧面厚度、整数台阶、去高程时基础体积、升高后拾取、城市细块对称与离散河床方向。
- test:browser：实际 WebGL 绘制、持久 Canvas、13 国聚焦、城市进出、倾斜与滚轮、图层、检索、目录回退、无脚本、无障碍与其他 Wiki 功能。
- quality:site：站点链接及本地参考图误发布检查。
- 美术人工检查：参考图对照、层级交界、标签碰撞、海岸体积和城市构图。自动测试不代表美术达标。
